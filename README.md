# آيسكريم العاصمة | Ice Cream Al Asemah

منيو إلكتروني عربي تفاعلي، جاهز للنشر كموقع ثابت على GitHub Pages.

## المميزات

- قالب حديث متجاوب مع الجوال وهوية المحل.
- واجهة تفاعلية لتبديل الأصناف، مع انتقالات تدعم إعداد تقليل الحركة.
- البحث والتصنيفات والترتيب، وعرض المنتجات كبطاقات أو قائمة.
- المفضلة، واختيار الأحجام والإضافات، وسلة تحسب الإجمالي بالريال السعودي.
- مترجم صوتي إلى العربية من الإنجليزية والتركية والصينية والفرنسية والكردية السورانية والكرمانجية، حسب دعم المتصفح للغة والصوت.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. فك ضغط الملف وارفع **الملفات الموجودة داخله** إلى جذر المستودع. يجب أن يكون `index.html` في الجذر؛ رفع ملف ZIP وحده لا ينشر الموقع.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر فرع **main** ومجلد **/ (root)**، ثم اضغط **Save**.
5. افتح رابط الموقع الذي يظهر في صفحة Pages بعد اكتمال النشر.

الموقع لا يحتاج إلى تثبيت حزم أو تنفيذ خطوة بناء، ولا يعتمد على استضافة Sites.

## التشغيل على جهازك

من داخل مجلد الملفات شغّل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. يتطلب تشغيل الميكروفون إذن المستخدم ومتصفحًا يدعم التعرف الصوتي، ويفضل تجربة رابط HTTPS المنشور مباشرة عبر Chrome أو Edge.

## تعديل المحتوى

- `app.js`: الأصناف والأسعار والأوصاف والإضافات؛ ابحث عن `products` و`extras`.
- `index.html`: العناوين ومحتوى الصفحة.
- `style.css`: الألوان وتوزيع العناصر وتنسيق الجوال.
- `motion.js`: انتقالات النوافذ وظهور العناصر.
- `experience.js`: تبديل منتجات الواجهة وعرض البطاقات والقائمة.
- `voice-translator.js`: المترجم الصوتي.
- `assets/al-asemah-logo.png`: شعار المحل.

## ملاحظات التشغيل

الأصناف والأسعار والصور تجريبية وتحتاج إلى اعتماد المحل. السلة تحسب الاختيارات وتعرض ملخصًا، ولا ترسل الطلبات تلقائيًا ولا تتضمن دفعًا إلكترونيًا.

تُحفظ السلة والمفضلة وطريقة العرض في متصفح الزائر. بيانات النسخة المستضافة سابقًا لا تنتقل تلقائيًا إلى عنوان GitHub Pages.

التعرف الصوتي والنطق العربي يعتمدان على المتصفح والجهاز، وقد لا تتوفر الكردية صوتيًا؛ يبقى إدخال النص متاحًا. يستخدم المتصفح خدمته لمعالجة الصوت، وتُرسل النصوص إلى MyMemory للترجمة. تتطلب هذه الخدمة اتصالًا بالإنترنت ولها حصة مجانية يومية. لا يحفظ التطبيق التسجيلات أو النصوص في خادم خاص به.

توثيق خدمة الترجمة: https://mymemory.translated.net/doc/spec.php
